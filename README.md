
# Customer Shopping Behavior Analysis

## 📌 Overview
This project analyzes customer shopping behavior using a dataset of 3,900 purchase transactions. Using Python, MySQL, and Power BI, the project uncovers insights into customer spending patterns, subscription behavior, product performance, and customer segments. 【1-5ccf98】

## 🛠️ Tech Stack
- Python (Pandas)
- MySQL
- SQL
- Power BI

## 🔍 Data Preparation
- Handled missing values in review ratings.
- Standardized column names.
- Created new features such as age groups and purchase frequency.
- Loaded cleaned data into MySQL for analysis.

## 📊 Key Analyses
- Revenue by gender
- Top-rated products
- Customer segmentation (New, Returning, Loyal)
- Subscriber vs. non-subscriber behavior
- Discount usage analysis
- Revenue by age group
- Shipping method performance
- Top products by category 

## 📈 Dashboard
Interactive Power BI dashboard showcasing:
- Sales and revenue metrics
- Customer demographics
- Subscription insights
- Product category performance 

## 💡 Business Insights
- Promote subscriptions with exclusive benefits.
- Strengthen loyalty programs.
- Optimize discount strategies.
- Focus marketing on high-value customer segments.
- Highlight top-performing products.
